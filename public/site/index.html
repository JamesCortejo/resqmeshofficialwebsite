ResQMesh hardware

The local link that keeps emergency communication moving.

Each ResQMesh device combines an Orange Pi, LoRa radio, GPS module, local Wi-Fi hotspot, OLED status display, and battery monitoring. It connects nearby mobile users and carries essential emergency information across the mesh when internet or mobile service is unavailable.

  • LoRa mesh communication
  • GPS and device status
System overview

Designed for online access, emergency fallback communication, and rescue coordination.

The website is the control point for registration, approvals, devices, rescue teams, distress signals, and deployments. Online services support connected access when internet is available, while mesh devices keep local communication available when internet or mobile networks are weak.

The mobile app connects civilians and rescuers to the system in both modes. When internet is available, users can work through connected online services. When internet is unavailable, nearby mesh devices keep critical access and activity moving.
